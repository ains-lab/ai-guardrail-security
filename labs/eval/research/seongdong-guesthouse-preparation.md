# 검토 — 성동구 자가 단독주택의 게스트하우스 개업 준비

기준일: 2026-10-20 · 독자: 직접 운영을 준비하는 소유자 · 형식: 한국어 Markdown

## 목표 — 인허가 경로 선택과 공사 전 확인

검토 조건은 서울 성동구의 자가 단독주택, 소유자 비거주, 내·외국인 숙박객 수용이다. 정확한 주소, 건축물 면적·층수, 한옥 여부와 현재 건축물대장상 용도는 제공되지 않았다. 아래 판단은 소유자가 직접 영업하는 경우를 전제로 하며, 개별 주소에 대한 허가 가능 판정은 아니다.

성동구는 도시민박 등록 시 주민등록등본뿐 아니라 현장조사에서 실제 거주 여부를 확인한다. 비거주 소유자가 직접 운영하려는 조건에서는 주택을 소유했다는 사실만으로 외국인관광 도시민박업 요건을 충족하지 못한다.[9] 내국인 수용 예외가 존재해도 비거주 운영까지 자동 허용되는 것은 아니다.[5][8]

이 문서를 읽고 할 수 있는 일은 적합한 업종 후보를 고르고, 구청 사전상담 자료를 준비하고, 허가 가능성 확인 전 지출을 보류하는 것이다. 건축·소방 설계 경험은 전제하지 않는다. 개별 건물의 적법성 검토, 세액 계산, 실제 신청 대행과 허가 취득은 범위 밖이다.

목차: 업종 선택 → 건축·입지 검토 → 신고·안전 준비 → 운영·비용 준비 → 상담 체크리스트 → 용어·오해·출처.

## 선택 — 운영 조건별 인허가 경로

‘게스트하우스(Guest House)’는 영업상 명칭이다. 이름이 아닌 실제 시설과 영업방식에 따라 적용 제도를 선택해야 한다. 공중위생관리법상 숙박업과 등록된 도시민박·한옥체험업은 구분된다.[7]

```text
비거주 소유자의 직접 운영 + 내·외국인 수용
  ├─ 일반 주택 → 숙박시설 입지·용도변경 가능성 → 숙박업 신고 검토
  ├─ 법정 한옥 → 한옥체험업 등록기준·관리자 배치 검토
  └─ 주택 유지 + 도시민박 → 실제 거주 및 내국인 허용 근거 별도 검토
                              특례를 비거주 면제로 간주하지 않음
```

| 후보 | 비거주·내외국인 조건과의 관계 | 먼저 확인할 사항 |
| --- | --- | --- |
| 공중위생관리법상 숙박업 | 도시민박과 다른 일반 숙박영업 경로로 우선 검토 | 숙박시설 입지·건축물 용도 적합성, 필요 용도변경과 시설 기준[7] |
| 한옥체험업 | 서울스테이 안내에 이용범위 ‘내외국인’, 호스트 거주의무 ‘X’ 명시 | 법정 한옥 해당성, 숙박 체험 공간 연면적 230㎡ 미만, 전통문화 체험시설, 영업시간 관리자 배치[6] |
| 일반 외국인관광 도시민박업 | 직접 비거주 운영 조건과 불일치 | 자신이 거주하는 주택 요건, 외국인 대상 원칙 및 예외의 개별 적용[5][9] |
| 공유숙박 규제특례 | 내국인 허용의 조건부 경로이지 비거주 면제의 보편 근거가 아님 | 사업자별 현재 승인·유효기간·신규 접수·거주·예약채널 조건[8] |
| 실제 거주 임차인의 운영 | 소유자 비거주와 영업자 비거주는 다른 경우 | 임차인의 실질 운영·거주, 소유자 동의와 사용권 서류를 별도 상담[9] |

공중위생 숙박업은 성동구 안내상 취사시설 미포함인 숙박업(일반), 취사시설 포함인 숙박업(생활)로 나뉜다. 객실·공용주방 제공 방식을 정하기 전에 관할에 분류를 확인한다.[10] ‘자가 주택이므로 별도 용도 검토가 없다’거나 ‘주방만 설치하면 생활숙박업이 된다’고 판단해서는 안 된다.[7][10]

### 예외 — 내국인 수용과 실거주 조건의 분리

관광진흥법 시행령에는 도시재생활성화계획에 따른 마을기업이 외국인 이용에 지장을 주지 않는 범위에서 내국인에게 지역문화 체험 숙식을 제공하는 예외가 있다. 단순히 도시재생지역에 있거나 협동조합을 설립하는 것만으로 해당 예외가 적용된다고 해석할 수 없다.[5]

ICT 규제샌드박스의 미스터멘션 승인사례에는 서울·부산, 호스트별 연간 180일 이내 등의 조건과 함께 영업시설 거주 사실 확인 조건이 기재되어 있다. 해당 페이지는 특정 승인사례의 조건이므로 모든 플랫폼의 현재 조건이나 신규 진입 가능성을 증명하지 않는다.[8] 사업자가 제시하는 최신 지정서·임시허가서와 변경 부가조건을 확보한 뒤 구청과 대조하는 것이 필요하다.

서울스테이는 한옥체험업에 호스트 거주의무가 없다고 안내하지만 영업시간 동안 한옥 관리자를 배치하도록 한다. 비거주 가능성을 무인 운영 가능성으로 바꾸어 해석하지 않는다. 일반 주택의 한옥풍 인테리어만으로 법정 한옥 요건을 대신할 수 있다고 보지 않는다.[6]

**조건부 권고:** 비거주 직접 운영을 유지한다면 우선 건축사와 성동구에 숙박시설 전환 가능성을 문의한다. 법정 한옥에 해당한다면 한옥체험업을 병렬 검토한다. 용도변경이 불가능하고 한옥도 아니라면, 현 조건 그대로 가능한 사업이라고 전제하지 말고 거주·운영주체 또는 사업계획 변경을 검토한다. 이는 위 근거에서 도출한 판단이며 개별 허가 확정이 아니다.

## 제약 — 주소별 건축·입지 적합성

숙박업의 입지와 건축물 용도가 맞아야 하므로, 객실 인테리어보다 토지·건물 서류 검토를 먼저 진행한다. 법제처의 숙박업 비교자료는 숙박시설의 건축이 가능한 곳을 전제로 하며, 서울의 다른 자치구 숙박업 안내도 건축물 용도와 학교 관련 제한을 확인항목으로 제시한다.[7][1]

```text
소유권 확인 ≠ 숙박업 허용
정확한 주소 → 입지 제한 → 용도변경 가능성 → 건축·소방 설계 → 공사
                         불가/비용 과다 → 공사 보류·사업안 수정
```

다음은 **성동구·건축사 사전확인용 목록**이며 모든 항목이 모든 주택에 동일하게 적용된다는 뜻은 아니다.

- 건축물대장: 현재 용도, 연면적·층별 면적, 사용승인일, 위반건축물 표시, 현장과 도면의 일치.
- 토지이용계획: 용도지역·지구·구역, 지구단위계획, 정비사업 및 개별 필지의 숙박시설 허용 여부.
- 교육환경: 학교 주변 제한의 해당 여부와 필요한 심의·협의 가능성.
- 용도변경: 허가·신고·대장 변경 중 어떤 절차가 필요한지와 관련 설계·공사 범위.
- 건축 성능: 주차, 접도, 구조, 피난계단·출구, 방화구획, 채광·환기, 장애인 편의시설의 적용 여부.
- 부대설비: 전기 용량·검사, 가스·보일러, 급배수, 하수·정화조, 불법 증축·지하 객실 계획.

영등포구의 ‘상업지역’ 안내를 성동구 모든 필지에 그대로 적용하지 않는다. 실제 주소의 서울시 조례·지구단위계획과 건축 심사를 확인해야 한다.[1] 주차대수, 스프링클러 설치범위, 필요한 출구 수는 현 건물 정보 없이 확정하지 않는다.

## 준비 — 신고·소방·위생 절차

성동구 숙박업 안내는 영업시설 및 설비개요서, 교육필증과 본인 신분증을 제시하며 민원여권과 허가민원팀을 문의처로 안내한다. 안내된 신고 처리시간은 즉시(3시간 이내)지만 건축 검토·공사·소방 준비 전체 기간이 아니라 신고 처리 단계의 안내다.[10]

```text
입지·용도 사전상담 → 업종 결정 → 설계·관계부서 협의 → 적법한 공사
→ 교육·시설서류 확보 → 업종별 신고/등록 → 사업자등록·보험 확인 → 예약 개시
```

### 확인 — 일반 숙박업 서류와 관계기관 협의

- 성동구에 영업신고서, 영업시설·설비개요서, 교육필증 등 현재 제출목록을 요청한다.[10]
- 건축물대장·토지이용계획·평면도·소유권 자료는 사전상담용으로 준비한다. 영등포구 안내는 숙박업 신고와 관련하여 전기·승강기·가스·도면 등도 확인하므로, 성동구에 건물별 적용 서류를 문의한다.[1]
- 관할 소방서와 소방 설계 담당자에게 최종 업종·층수·면적·정원을 제시하고 소화·경보·피난설비, 소방안전관리, 필요한 증빙과 검사 범위를 확인한다. 도시민박 기준을 일반 숙박시설의 전체 기준으로 대체하지 않는다.
- 재난배상책임보험·화재배상책임보험 등의 적용·중복/제외 관계, 가입기한과 보장대상은 확정 업종으로 구청·보험사에 서면 문의한다. 이번 자료로 개별 시설의 의무보험 종류와 가입기한을 확정하지 않았다.

### 확인 — 도시민박으로 사업안을 변경하는 경우

성동구 도시민박 안내는 등록신청서·사업계획서·평면도·소유/사용권 증빙·주민등록등본·이웃 동의서 등을 요구하고, 현장 실제 거주도 확인한다. 위반건축물·불법증축, 지하·반지하, 방이 1개인 집, 미닫이 문 형태의 방에 관한 제한과 30년 이상 건축물 안전점검보고서도 안내한다.[9]

성동구 안내의 ‘빌라/단독주택: 전세대’ 이웃 동의 범위는 독립 단독주택에서 누구를 뜻하는지 담당부서 해석을 받아야 한다. 해당 요구를 전국 법령 공통 기준으로 확대하지 않는다.[9]

소방설비 관련 안내에는 소화기, 객실별 감지기·일산화탄소 경보기, 3층 이상 완강기 및 피난 관련 배치 표시가 포함된다. 개별 건물 적용은 현장확인 대상으로 남긴다.[9] 위 도시민박 서류를 일반 숙박업이나 한옥체험업의 제출목록으로 혼용하지 않는다.

## 운영 — 개업 후 관리와 사업자등록

합법적인 시설 확보 후에도 위생·세무·예약 관리가 이어진다. 법제처 안내는 투숙객이 바뀔 때마다 침구 커버와 수건을 세탁하고, 용도별 청소도구를 구분하는 등 숙박시설 위생관리를 설명한다.[2]

```text
시설 적법성 → 영업 적법성 → 반복 운영의 안전·위생·정산
인허가 완료            ≠ 청소·민원·사고 대응의 완료
```

### 지침 — 운영 준비물과 확인사항

- 청소·세탁: 객실 회전 점검표, 침구 교체, 오염물 분리, 소독·해충 관리 및 외주 계약을 준비한다.[2]
- 응급대응: 야간 연락망, 출입 장애·누수·가스 의심·화재 시 대응, 피난안내와 외국어 안내를 준비한다. 비거주 소유자에게 현장 출동·관리인 체계는 운영상 권고다.
- 음식·취사: 조식 제공·조리 판매·공용주방의 계획을 신고 전에 설명하고 별도 식품위생 신고·교육 적용을 확인한다. 모든 숙박업에 조식 제공 예외가 있다고 가정하지 않는다.
- 세무: 국세청 안내상 계속적·반복적 유상 공유숙박은 사업자등록 대상이며 사업장마다 개시일부터 20일 이내 신청을 안내한다. 개시 전 신청도 가능하다. 세무등록이 숙박 인허가를 대신하지는 않는다.[3]
- 세금·계약: 실제 업종코드, 일반/간이과세, 부가가치세·종합소득세, 공사 매입세액과 주택 용도변경의 세금·대출 영향을 세무사·금융기관에 확인한다. 세액·세율은 이 문서에서 산정하지 않았다.
- 예약·개인정보: 총요금·추가인원·취소환불·소음·흡연·반려동물·파손 규정을 정한다. 개인정보 수집 최소화, 보관·파기, 도어록 코드 교체, CCTV 촬영범위·안내 및 미성년자 확인 방식을 법률 검토 대상으로 둔다.
- 판매채널: 온라인 여행사(OTA, Online Travel Agency)와 플랫폼의 인허가 증빙·보험·수수료·정산 정책을 확인한다. 플랫폼에 등록 가능하다는 답변만으로 합법성을 판단하지 않는다.

### 비용 — 시설 적법성 확보와 운영비의 분리

정확한 면적·도면·현장 견적이 없으므로 공사비·매출·손익분기점은 숫자로 제시하지 않는다. 아래는 계산 틀이며 측정값이나 수익 보장이 아니다.

```text
초기비용 = 설계·용도변경 + 건축·소방·설비공사 + 가구·침구
         + 신고·교육·검사·보험 + 사진·판매준비 + 예비비
월 운영비 = 관리인 + 청소·세탁 + 전기·수도·가스 + 플랫폼·결제 수수료
          + 보험·유지보수·소모품 + 세금·대출비용
매출 추정 = 판매가능 객실박 × 가정 점유율 × 가정 평균 객실단가
```

숙박시설 전환의 가능성·공사 범위가 정해져야 견적 비교가 가능하므로, 예약 예상매출보다 법적 전환 비용과 철수 가능한 지출 순서를 먼저 검토한다.

## 점검 — 성동구 사전상담 자료와 실행 순서

이 절은 허가 신청 완료가 아니라 상담 준비 목록이다. 주소와 도면을 바탕으로 관계부서의 회신을 받아야 다음 단계의 비용을 결정할 수 있다.

```text
서류 확보 → 구청·건축사 동시 검토 → 서면 회신 → 견적·사업성 판단
       → 업종 확정 → 공사·신고 → 보험·세무·운영 준비 → 개업
```

- [ ] 현장 사진과 층별 평면도, 면적·방 수·욕실·주방·계단·출입구 위치.
- [ ] 준공연도·불법 증축 여부, 한옥 해당 가능성, 기존 임차인·공유지분 여부.

## 부록 A — 용어

- 외국인관광 도시민박업: 도시 주민이 자신이 거주하는 법정 주택을 이용해 외국인 관광객에게 가정문화 체험 숙식을 제공하는 업. 법정 예외가 별도로 존재한다.[5]
- 한옥체험업: 법정 한옥에 관광객 숙박 또는 전통문화 체험시설을 갖추어 제공하는 관광사업.[6]
- 숙박업 일반/생활: 성동구 안내상 취사시설 미포함/포함으로 구분되는 공중위생 숙박업.[10]
- 규제샌드박스: 특정 사업의 승인범위·기간·부가조건 아래 규제를 달리 적용하는 제도. 한 승인사례가 모든 숙소에 적용되는 일반법은 아니다.[8]

## 부록 B — 오해와 미해결 사항

### 함정 — 소유·등록·플랫폼의 혼동

- 자가 소유와 영업자 실제 거주는 별개다. 전입신고 서류만 마련하고 실제 거주하지 않는 방식은 성동구 현장확인과 충돌한다.[9]
- 내국인 수용이 항상 불가능한 것은 아니다. 마을기업 예외·한옥체험업·개별 특례가 있으나 조건을 분리해야 한다.[5][6][8]
- 한옥체험업의 비거주 가능성은 무인 운영 면제를 뜻하지 않는다.[6]
- 사업자등록, 플랫폼 가입, 영업상 명칭은 인허가 적합성을 대신하지 않는다.[3][7]

### 한계 — 근거의 범위와 신뢰도

판단 신뢰도는 도시민박의 거주 요건·성동구 절차에 대해서는 높음, 해당 건물의 일반 숙박업 전환 가능성에는 미판정이다. 핵심 거주 요건은 국가법령정보센터, 성동구, 법제처 설명을 교차 확인했고 내국인 예외도 별도로 확인했다.[5][9][7] 한옥체험업 비거주 안내는 서울관광재단 공식 설명으로 확인했으나 대상 건물의 해당성·개별 등록 가능성은 확정하지 않았다.[6]

성동구 페이지는 직접 추출·TLS 인증서 확인 실패 후 실제 브라우저 본문으로 복구했다. 첨부 신청서 원문 전체를 대신 검토한 것은 아니다. 문서의 소방·건축·보험·세무 상담 목록 중 개별 적용이 필요한 항목은 확정 법률요건으로 단정하지 않았다.

법령 제2조 페이지는 2026-08-04 시행 표시를 확인했다. 나머지 안내 페이지는 2026-10-20 조회한 현행 웹 안내이며 과거 특정 시점의 보존본이 아니다. 미시행 법 개정이나 보도자료상 정책 방향을 현재의 보편 허용으로 적용하지 않았다.

2026년 플랫폼별 특례 신규 모집·임시허가 전환·유예기간은 별도 승인서 확인이 남아 있다. 병렬 조사에서 정부 발표와 사업자 안내의 변경 가능성이 발견되었으나, 본 문서는 개별 신규 진입기한을 확정하지 않는다. ‘모든 특례가 비거주를 허용한다’ 또는 ‘어떤 특례도 비거주를 허용할 수 없다’는 포괄 주장은 채택하지 않았다.

정확한 주소, 건물 용도·면적·층수, 한옥 여부, 도시재생활성화계획 포함 여부, 교육환경·주차·소방 적용, 보험 기한·종류, 세금·대출 영향은 미해결 항목이다. 임의로 영업 가능하다는 결론을 내리지 않았다.

### 판단자료 — 다음 단계 입력

- 우선순위: 비거주 직접 운영 유지 여부 → 법정 한옥 여부 → 일반 숙박시설 전환 가능성.
- 유력 선택: 일반 숙박업 사전검토, 한옥 해당 시 한옥체험업 병렬 검토.
- 보류 선택: 일반 도시민박의 비거주 직접 운영; 현재 거주 요건과 맞지 않음.
- 위험: 입지 부적합, 위반건축물, 용도변경 비용, 특례 조건 오인, 공사 선집행.
- 승인 전 행동: 서류 확보와 구청 서면상담. 영업 예약 접수·공사 계약은 적법 경로 확인 후 결정.
